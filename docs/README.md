# Documentation

This folder holds the notes that explain how the analysis was built and checked.

If you are new to the repository, these are the useful starting points:

- `variable_dictionary.md` — DHS variables and coding decisions;
- `diagnostics_review_2026-09-23.md` — current MCMC and robustness diagnostics;
- `analysis_audit_2026-09-23.md` — corrections made while validating the thesis analysis;
- `executed_environment_2026-09-23.md` — software versions present during the strengthened diagnostic run;
- `publication_strengthening_roadmap.md` — what still matters before submission.

The dated audit files are intentionally kept as a record of how the project changed. When an older note conflicts with the current manuscript or the final aggregate result tables, the newer result tables and current diagnostics note take precedence.
